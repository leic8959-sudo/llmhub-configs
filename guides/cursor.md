# Cursor

1. Получите ключ в личном кабинете LLMHub.
2. Откройте настройки Cursor и найдите раздел моделей/API keys.
3. Выберите OpenAI-compatible подключение или включите переопределение OpenAI
   base URL — название зависит от версии Cursor.
4. Укажите `https://llmhub.vip/v1` и сохраните ключ в поле credentials.
5. Добавьте точный ID модели из `GET /v1/models`, например
   `gpt-5.6-terra`, если он доступен вашему аккаунту.
6. Выполните короткий запрос в новом чате и проверьте usage в кабинете.

Не добавляйте ключ в `.cursor`, репозиторий или скриншот. Если текущая версия
Cursor не позволяет задать custom base URL для нужного режима Agent, сначала
проверьте обычный Chat; доступность функций Cursor не следует из одной только
совместимости API.
