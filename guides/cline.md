# Cline и Roo Code

1. Откройте настройки провайдера расширения.
2. Выберите `OpenAI Compatible`.
3. Base URL: `https://llmhub.vip/v1`.
4. API key: ключ из кабинета LLMHub.
5. Model ID: точное значение из `/v1/models`.
6. Сохраните конфигурацию и отправьте короткий запрос без доступа к файлам.
7. Только после этого разрешайте инструменты и работу с репозиторием.

Если расширение отдельно спрашивает context window или max output, не
угадывайте значения: используйте сведения каталога выбранной модели.
